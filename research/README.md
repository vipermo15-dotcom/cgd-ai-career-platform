# 교육생별 추천 채용공고 배포 (기준일 2026-09-30)

- 대상: 진로지도 자료가 있는 교육생 18명 중 3명(장아름·김규연·박민서) 제외한 15명 (수료 후 미취업 가정), 1인당 공고 10건
- `data/<이름>.json`: 조사 원본 / `out/<이름>_추천채용공고.html`: 개인별 단독 실행 파일(외부 의존 없음)
- 재생성: `python3 research/build.py`
- **비공개 자료**: 개인 진로 정보 포함. 저장소를 비공개로 유지하고 GitHub Pages로 노출하지 말 것. 교육생에게는 본인 파일만 개별 전달.

## 배포 전 확인 사항
1. 링크 유효성은 조사 세션의 스크랩 결과이며 독립 재검증 전. 마감이 임박한 공고가 많으므로 배포 직전 표본 재확인 권장.
2. 공고 본문이 이미지인 항목은 필수·우대·툴이 비어 있음(파일 내 `gap`에 표기).
3. 학생 문서가 가명(예: 소현, 민지)인 경우가 있어 실제 교육생과 매칭 담당자 확인 필요.
4. 취업 여부 자료가 저장소에 없어 전원을 미취업으로 가정. 이미 취업한 교육생은 제외할 것.
5. 장혜정: 랜딩페이지(UX/UI)와 포트폴리오 가이드(이커머스·편집)의 방향이 달라 UX/UI 기준으로 작성.
