# 링크드인 학과 홍보·게시물 운영 PRD - 교수자용

## 개요

이 문서는 교수자 본인의 **LinkedIn 개인계정**으로 컴퓨터그래픽실무자양성과정(CGD)을 홍보하고,
게시물을 정기적으로 기획·작성·검수·예약 발행·분석하는 운영 체계를 정의한 제품 요구사항 문서(PRD)입니다.
게시물 등록은 LinkedIn 공식 연동 도구인 **Buffer**로 예약 발행하고, 초안 작성은 Claude를 활용합니다.

**문서 유형**: PRD (Product Requirements Document)
**운영 채널**: LinkedIn 개인 프로필 (교수자 본인 계정)
**발행 도구**: Buffer (LinkedIn 채널 연동) + Claude (초안·이미지 기획)
**최종 수정**: 2026년 10월

---

## 1. 배경과 목표

### 1.1 배경

- 학과 홍보가 교육원 공식 채널·모집 공고에 의존해, 디자인 업계 실무자·인사담당자에게 직접 닿는 경로가 없다.
- 교육생 작업물과 취업 성과가 수업 안에서만 소비되고 외부에 축적되지 않는다.
- LinkedIn은 기업 인사·실무자가 상주하는 채널로, 교수자 개인 계정의 신뢰도를 활용하면 회사 페이지보다 도달률이 높다.

### 1.2 문제 정의

| 문제 | 현재 상태 | 목표 상태 |
|------|-----------|-----------|
| 외부 인지도 | 업계에서 과정 인지도 낮음 | 디자인 업계 1촌·팔로워 네트워크 내 상시 노출 |
| 게시 지속성 | 비정기·즉흥 게시 | 주 2~3회 예약 발행 |
| 교육생 취업 연결 | 작업물이 외부에 노출되지 않음 | 작업물 게시 → 기업 문의·채용 연결 |
| 성과 측정 | 측정 안 함 | 월간 지표 리포트로 개선 |

### 1.3 목표

1. **인지도**: 디자인·콘텐츠 업계 실무자에게 과정과 교육생 역량을 알린다.
2. **모집**: 예비 수강생(전직·재취업 희망자)의 문의를 늘린다.
3. **기업 네트워크**: 채용 담당자와의 연결을 늘려 교육생 추천·채용으로 잇는다.
4. **운영 효율**: 주 2시간 이내로 운영 가능한 반복 루틴을 만든다.

### 1.4 범위

| 포함 (In Scope) | 제외 (Out of Scope) |
|-----------------|---------------------|
| 교수자 개인 프로필 정비 | 교육원 공식 회사 페이지 운영 |
| 게시물 기획·작성·검수·예약 발행 | 유료 광고(LinkedIn Ads) |
| 댓글·DM 응대 기준 | 자동 댓글·자동 좋아요·자동 1촌 요청 |
| 월간 성과 리포트 | 타 SNS(인스타그램 등) 교차 운영 |

## 2. 대상 독자 (페르소나)

## 4. Phase 0 — 준비 (1주차)

### 4.1 개인 프로필 정비

- [ ] **헤드라인**: 직함 + 과정명 + 가치 한 줄
  - 예: `컴퓨터그래픽실무자양성과정 교수 | AI 디자인 실무 교육 | 교육생 포트폴리오·취업 연결`
- [ ] **소개(About)**: 과정 소개 3줄 + 교육 방식 + 연락 방법(문의 경로)
- [ ] **배너 이미지**: 과정명·대표 교육생 작업물 콜라주 (1584×396px)
- [ ] **추천(Featured) 섹션**: 과정 소개 페이지, 포트폴리오 워크플로우(`docs/portfolio-workflow.html` 배포 페이지), 대표 게시물 고정
- [ ] **경력**: 현 소속 기관·과정을 명시
- [ ] **크리에이터 모드**: 켜고 주제 해시태그 5개 지정 (#디자인교육 #그래픽디자인 #포트폴리오 #AI디자인 #취업)
- [ ] **계정 보안**: 2단계 인증 활성화

### 4.2 동의·준수 체계

- [ ] 교육생 **작업물·이름·얼굴 게시 동의서** 양식 준비 (부록 C) — 동의 없이는 게시하지 않는다.
- [ ] 소속 기관의 **대외 홍보 지침** 확인 (기관명·로고 사용 범위, 사전 승인 필요 여부)
- [ ] 금칙 표현 목록 확정 (4.3)

### 4.3 금칙·주의 표현

| 금지 | 이유 | 대체 표현 |
|------|------|-----------|
| "취업 100% 보장", "무조건 취업" | 허위·과장 우려 | "수료생 ○명이 ○○ 분야에 취업했습니다" (확인된 사실만) |
| 근거 없는 취업률·연봉 수치 | 사실 확인 불가 | 공식 집계 수치 + 기준 시점 명시 |
| 교육생 실명·얼굴 (미동의) | 개인정보·초상권 | 이니셜, 작업물만 게시 |
| 타 교육기관 비교·비방 | 분쟁 소지 | 우리 과정의 특징만 서술 |
| 채용 기업 실명 (미승인) | 기업 측 동의 필요 | "콘텐츠 디자인 스타트업" 등 업종 표기 |

## 5. Phase 1 — 구축 (2~3주차)

### 5.1 콘텐츠 필러 (5종)

| # | 필러 | 비율 | 내용 | 주 타깃 |
|---|------|------|------|---------|
| 1 | 교육생 작업물 | 30% | 프로젝트 결과물 + 기획 의도 + 사용 툴 | 기업 실무자 |
| 2 | 수업·실습 현장 | 20% | 수업 장면, 피드백 과정, 특강 | 예비 수강생 |
| 3 | 취업·수료 성과 | 20% | 취업 소식, 수료 전시, 수료생 인터뷰 | 전체 |
| 4 | AI 디자인 인사이트 | 20% | Claude·Midjourney 등 AI 툴 실무 활용 팁 | 업계 실무자 |
| 5 | 모집·행사 안내 | 10% | 모집 일정, 설명회, 수료 전시 초대 | 예비 수강생 |

### 5.2 게시 포맷

| 포맷 | 용도 | 규격 |
|------|------|------|
| 텍스트 + 단일 이미지 | 작업물 1점, 소식 | 1200×1200px 또는 1080×1350px |
| 캐러셀 (PDF 문서) | 프로젝트 케이스스터디, 팁 정리 | 1080×1350px, 5~10장 |
| 다중 이미지 | 수업 현장, 전시 | 최대 9장 |
| 짧은 영상 | 작업 과정 타임랩스 | 30~90초, 세로 또는 정사각 |
| 텍스트 전용 | 인사이트, 회고 | 1,300자 이내 |

### 5.3 게시물 기본 구조

```
[훅] 첫 2줄 — 피드에서 '더보기' 전에 보이는 부분. 질문·숫자·반전으로 시작
[본문] 맥락 → 과정 → 결과 (3~6문단, 문단당 1~3줄)
[CTA] 행동 유도 1개 — 댓글 질문 / 프로필 방문 / 문의 경로
[해시태그] 3~5개 (부록 B)
```

- 외부 링크는 본문 대신 **첫 댓글**에 넣는다 (본문 링크는 도달률 저하 경향).
- 교육생을 언급할 때는 동의를 받은 경우에만 `@멘션`한다.

### 5.4 Buffer 설정

- [ ] Buffer 계정 생성 → **LinkedIn 개인 프로필** 채널 연결
- [ ] 발행 시간 슬롯 설정 (한국시간): 화·목 08:30, 수 12:00 (2분기부터 월 08:30 추가)
- [ ] 계정 시간대를 `Asia/Seoul`로 확인
- [ ] 필러별 **아이디어 그룹**(Ideas 컬럼) 5개 생성: 작업물 / 현장 / 성과 / 인사이트 / 모집
- [ ] 반복 포맷을 **게시물 템플릿**으로 등록 (부록 A의 3종)

### 6.2 월간 콘텐츠 캘린더 (예시)

| 주 | 화 08:30 | 수 12:00 | 목 08:30 |
|----|----------|----------|----------|
| 1주 | 작업물 (편집디자인 프로젝트) | 인사이트 (AI 툴 팁) | 현장 (중간 크리틱) |

| 4주 | 성과 (수료생 인터뷰) | 작업물 (숏폼 콘텐츠) | 월간 회고 / 다음 달 예고 |

### 6.3 Claude 초안 작성 프롬프트

```
너는 컴퓨터그래픽실무자양성과정 교수의 LinkedIn 게시물 작성자야.
아래 소재로 LinkedIn 게시물 초안을 작성해줘.

- 필러: [교육생 작업물 / 수업 현장 / 취업 성과 / AI 인사이트 / 모집 안내]
- 소재: [프로젝트명, 기간, 사용 툴, 핵심 성과]
- 타깃: [디자인 기업 실무자 / 예비 수강생]
- 동의 범위: [실명 가능 / 이니셜만 / 작업물만]

조건:
1. 첫 2줄은 피드에서 멈추게 하는 훅 (질문 또는 구체적 숫자)
2. 본문은 맥락 → 과정 → 결과, 문단당 1~3줄, 전체 800~1,200자
3. 과장·보장 표현 금지, 확인된 사실만
4. CTA 1개, 해시태그 3~5개
5. 톤: 따뜻하지만 전문적, 교육자의 관점
6. 버전 2개 (짧은 버전 / 긴 버전)
```

### 6.4 발행 전 검수 체크리스트

- [ ] 교육생 동의서 확인 (실명·얼굴·작업물 범위 일치)
- [ ] 수치·사실 확인 (취업 소식은 본인 확인 완료)
- [ ] 금칙 표현 없음 (4.3)
- [ ] 기업명 언급 시 기업 측 승인 여부
- [ ] 이미지 규격·텍스트 가독성 (모바일에서 확인)
- [ ] 오탈자, 링크는 첫 댓글로 분리
- [ ] 대외 발행물 자동 기초 점검 (선택: marketing-team 규제검토자 `staff-gate-auditor`로 사전 점검)

### 6.5 역할 분담 (RACI)

| 작업 | 교수자 (계정 주인) | 보조 강사·조교 | 교육생 |
|------|:---:|:---:|:---:|
| 소재 수집 | A | R | C (작업물 제공) |
| 초안 작성 | A | R | – |
| 검수·승인 | R/A | C | C (본인 게시물 확인) |
| Buffer 예약 | R/A | – | – |
| 댓글·DM 응대 | R/A | – | I |
| 월간 리포트 | A | R | I |

> R=실행, A=최종 책임, C=협의, I=공유. 계정 로그인 권한은 교수자만 보유하고, 보조 인력은 Buffer 팀원 권한(초안 작성)으로만 참여한다.

### 6.6 댓글·DM 응대 기준

| 유형 | 응대 시간 | 응대 방식 |
|------|-----------|-----------|
| 모집 문의 | 24시간 이내 | 모집 일정·공식 안내 링크 제공 |
| 채용·교육생 추천 문의 | 24시간 이내 | 직무 요건 확인 → 교육생 매칭 (`anthropic-skills:career-matching` 활용) |
| 일반 댓글 | 당일 | 감사 + 후속 질문 |
| 부정적 댓글 | 48시간 이내 | 사실 확인 후 정중히 응대, 논쟁 회피 |

## 7. Phase 3 — 측정·개선 (월간·분기)

### 7.1 월간 리포트 (매월 첫 주)

1. Buffer 지표로 지난달 전체 게시물 집계 (노출·반응·댓글·공유·클릭)
2. 필러별 평균 성과 비교 → 상위·하위 필러 파악
3. 상위 3개 게시물 분석 (훅 유형, 포맷, 발행 시간)
4. 문의 건수 수기 집계 (모집 / 채용)
5. 다음 달 필러 비율·발행 시간 조정

| 발행 수 | | | |
| 평균 노출 | | | |
| 평균 반응률 | | | |
| 팔로워 증가 | | | |
| 문의 건수 | | | |
| 최고 성과 게시물 | | | |

### 7.2 개선 규칙

- 반응률 상위 게시물은 4~6주 후 **포맷을 바꿔 재활용** (단일 이미지 → 캐러셀 등)
- 2개월 연속 하위 필러는 비율을 줄이거나 훅·포맷을 교체
- 발행 시간은 분기마다 A/B 비교 (같은 필러를 다른 시간대에 발행)

### 7.3 분기 회고

- KPI 달성 여부 점검, 다음 분기 목표값 재설정
- 교육생·수료생 피드백 수렴 (게시 경험, 기업 연락 여부)
- 운영 루틴 소요 시간 점검 (주 2시간 초과 시 단계 축소)

## 8. 워크플로우 상세

### 8.1 게시물 상태 흐름

```
아이디어 ──▶ 초안 ──▶ 검수 ──▶ 예약 ──▶ 발행 ──▶ 분석
(Buffer Ideas) (Claude)  (체크리스트) (Buffer 큐)  (LinkedIn)  (월간 리포트)
                          │
                          └─▶ 반려 (동의 미확인·사실 불명확) ──▶ 초안으로 복귀
```

### 8.2 Buffer 연동 절차 (Claude + Buffer MCP)

Claude 세션에서 Buffer MCP가 연결되어 있으면 아래 순서로 예약·분석을 요청할 수 있다.
**모든 예약은 교수자가 최종 문안을 확인한 뒤에만 진행한다.**

| 단계 | Buffer 도구 | 용도 |
|------|-------------|------|
| 1 | `get_account` | 조직(organization) ID와 계정 시간대 확인 |
| 2 | `list_channels` | LinkedIn 개인 프로필 채널 ID 확인 |
| 3 | `list_idea_groups` / `create_idea` | 필러별 아이디어 등록 |
| 4 | `list_post_templates` / `create_post_template` | 반복 포맷 템플릿 관리 |
| 5 | `create_post` | 확정본을 큐에 추가 (기본: 큐 추가, 필요 시 지정 시간) |
| 6 | `list_posts` / `edit_post` | 예약 목록 확인·수정 |
| 7 | `get_aggregated_post_metrics` | 기간별 LinkedIn 성과 합계·평균 조회 |

**Claude 요청 예시**

```
이번 주 확정된 게시물 3건을 Buffer의 내 LinkedIn 채널 큐에 추가해줘.
예약 전에 채널 이름과 예약될 시간을 먼저 보여주고 내 확인을 받아.
```

```
Buffer에서 지난달 LinkedIn 게시물 성과를 집계해서 7.1 리포트 양식으로 정리해줘.
```

| 운영 중단 (바쁜 시기) | 지속성 저하 | 비수기에 2~3주 분량 선제 예약, 최소 주 1회 유지 |

## 10. 로드맵과 체크리스트

### 10.1 일정

| 기간 | Phase | 핵심 산출물 |
|------|-------|-------------|
| 1주차 | Phase 0 준비 | 정비된 프로필, 동의서 양식, 금칙 목록 |
| 2~3주차 | Phase 1 구축 | 콘텐츠 필러·템플릿, Buffer 채널·슬롯·아이디어 그룹 |
| 4주차~ | Phase 2 운영 | 주 2~3회 예약 발행, 주간 루틴 정착 |
| 매월 첫 주 | Phase 3 측정 | 월간 리포트, 다음 달 캘린더 |
| 분기 말 | Phase 3 회고 | KPI 점검, 목표 재설정 |

### 10.2 Phase별 완료 기준

- [ ] **Phase 0**: 프로필 항목 7개 완료, 동의서 양식 배포, 기관 지침 확인
- [ ] **Phase 1**: 필러 5종·템플릿 3종 확정, Buffer 채널 연결 및 슬롯 설정, 첫 달 캘린더 작성
- [ ] **Phase 2**: 4주 연속 주 2회 이상 발행, 검수 체크리스트 100% 적용
- [ ] **Phase 3**: 첫 월간 리포트 작성, 개선 액션 1개 이상 반영
