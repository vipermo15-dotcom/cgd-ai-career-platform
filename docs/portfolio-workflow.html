Phase 1 · 진로 설정
취업 방향 결정 & 사전 설문
Week 1~2 ▾

포트폴리오 제작 전 가장 중요한 단계입니다. 어떤 분야에 취업할 것인지 방향을 잡아야 포트폴리오의 톤 앤 매너, 작업물 선택 기준이 결정됩니다.

🎯

취업 분야 결정

브랜드 디자인 / SNS 마케팅 / 영상편집 / AI 생성 / 프리랜서 중 선택

📋

CGD 플랫폼 사전 설문 작성

보유 툴, 주요 작업물, AI 활용 여부, 희망 근무 형태 입력

🔍

희망 기업 리스트 3개 이상

규모·업종·분위기 기준으로 지원 가능 기업 조사

📂

진로지도 MD 파일 제출

선생님이 작성한 진로지도 문서를 USB → GitHub 업로드

사전 설문지 작성 및 제출 완료

Phase 2 · 서류 준비
이력서 · 자기소개서 · 포트폴리오 초안
Week 2~4 ▾

취업 서류의 3대 축을 동시에 진행합니다. 세 가지는 서로 연결되어 있으므로 포트폴리오 콘셉트를 먼저 잡은 뒤 이력서·자소서에 반영하세요.

📄

이력서 작성

CGD 플랫폼 서류 등록 센터에 업로드. AI 역량 분석 후 보완 진행

✍️

자기소개서 작성

플랫폼 AI 자기소개서 기능 활용. 지원 분야별 3개 버전 준비

🖼️

포트폴리오 작업물 선별

대표 작업물 5~10개 선정. 각 작업물의 제작 의도·툴·결과 정리

🤖

AI 역량 분석 실행

플랫폼의 AI 역량 분석 탭에서 내 강점·약점 파악 및 보완 계획 수립

이력서 초안 작성 완료
자기소개서 초안 1개 이상 완료
포트폴리오 수록 작업물 5개 이상 선정
AI 역량 분석 1회 이상 실행
선생님 1차 서류 검토 완료
CGD 플랫폼 Figma Photoshop Illustrator ChatGPT / Claude
3
Phase 3 · 플랫폼 등록
CGD 플랫폼 서류 업로드 완성
Week 3~5 ▾

CGD 취업지원 플랫폼에 모든 서류를 등록해야 취업 준비율 점수가 올라가고, 선생님이 진로지도 카드를 작성해 드릴 수 있습니다.

👤

프로필 완성 (20점)

바이오, 스킬, 전화번호, 학번 4가지 모두 입력 시 만점

💼

포트폴리오 등록 (20점)

서류 등록 센터 → 포트폴리오 탭에 작업물 업로드

📝

자기소개서 등록 (20점)

AI 자기소개서 탭에서 작성하거나 직접 업로드

🗺️

진로지도 면담 신청 (20점)

선생님과 진로지도 면담 후 카드 작성 — careerTrack + 메모

프로필 4항목 모두 입력 완료
포트폴리오 1개 이상 플랫폼 등록
자기소개서 1개 이상 플랫폼 등록
취업 준비율 40점 이상 달성
💡 취업 준비율 점수 구조: 프로필(20) + 자소서(20) + 포트폴리오(20) + 진로지도(20) + 취업활동(20) = 100점. 80점 이상이 목표입니다.

Phase 4 · 개인 브랜딩
포트폴리오 랜딩페이지 제작
Week 4~6 ▾

URL 하나로 나를 소개할 수 있는 포트폴리오 사이트를 만듭니다. 채용 담당자에게 카카오톡 링크로 바로 공유할 수 있어야 합니다.

🎨

디자인 시스템 선택

PlayStation 스타일(하이테크), Pinterest 스타일(따뜻함) 중 본인 분야에 맞는 것 선택

✏️

콘텐츠 구성

강점 3가지, 자격증, 경력, 연락처 정리. 진로지도 MD 파일 참고

🐙

GitHub 업로드

docs/이름/ 폴더에 HTML 파일 업로드. GitHub Pages 자동 배포

🔗

링크 확인 & 공유

모바일에서 링크 열어 확인 후 카카오톡으로 공유 가능한지 테스트

랜딩페이지 초안 완성
GitHub docs 폴더에 업로드
GitHub Pages 링크 작동 확인
모바일 화면 확인 완료
선생님 피드백 반영 수정 완료
GitHub Pages HTML/CSS Claude AI Figma (기획)

Phase 5 · 취업처 매칭
AI 취업처 추천 & 채용공고 분석
Week 5~8 ▾

플랫폼의 AI 자동 매칭 기능을 활용해 나에게 맞는 기업을 찾고, 각 기업의 채용공고를 분석하여 지원 전략을 세웁니다.

🤖

AI 취업처 추천 실행

진로지도 카드의 careerTrack + 스킬 기반 AI 맞춤 기업 리스트 생성

📊

채용공고 첨삭

플랫폼 채용공고 첨삭 탭 — 공고 요건과 내 서류 매칭 분석

🏢

기업 파이프라인 확인

학과 연계 기업 목록 확인. 공동훈련센터 협력사 우선 검토

⭐

희망기업 매칭 등록

6
Phase 6 · 취업 활동
지원서 제출 & 면접 준비
Week 7~12 ▾

실제 지원을 시작하는 단계입니다. 지원 현황을 플랫폼에 기록하고, AI 면접 코치를 활용해 면접을 대비합니다.

📮

지원서 제출

지원 현황 탭에서 상태 관리. 서류전형 → 면접 → 최종결과 업데이트

🎤

AI 면접 준비

AI 취업진로 에이전트 탭 — 예상 질문 생성 및 답변 연습

📱

포트폴리오 링크 전달

면접 전 채용 담당자에게 랜딩페이지 링크 카카오톡 발송

🔄

피드백 반영 & 재지원

서류 탈락 시 AI 분석으로 원인 파악 후 서류 수정 → 재지원

1개 이상 기업 지원 완료
지원 현황 플랫폼 기록 완료
AI 면접 준비 1회 이상
취업 상태 "지원중"으로 업데이트
💡 취업활동 점수: 미시작(0) → 준비중(8) → 지원중(14) → 취업확정(20). 지원서를 제출하면 바로 14점으로 올라갑니다!
7
Phase 7 · 사후 관리
취업 확정 보고 & 사후 지도
취업 후 ▾

취업이 확정되면 플랫폼에 결과를 업데이트하고, 학과 취업률 집계에 반영합니다. 입사 후에도 사후 지도를 통해 지원받을 수 있습니다.

🎉

취업 확정 보고

플랫폼 프로필 → 취업 상태를 "취업확정"으로 업데이트. 기업명 입력

📊

HRD-Net 보고서 제출

학과장 대시보드에서 HRD-Net 양식 엑셀/PDF 다운로드 후 제출

💬

사후 지도 등록

입사 3개월 후 적응 상황 피드백. 플랫폼 사후지도 메뉴에서 확인

⭐

플랫폼 피드백 작성

후배 교육생을 위한 취업 후기와 플랫폼 피드백을 남겨주세요

플랫폼 취업 상태 "취업확정" 업데이트
취업 기업명 및 직종 입력
플랫폼 피드백 작성 완료
